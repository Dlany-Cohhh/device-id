今日校园 · 设备ID

用今日校园 App 的「扫一扫」打开。纯静态页面，不联网、不上报，只在本机显示。
签到用设备ID（填到 accounts/<账号>.device_id）
等待 App 桥接…
App 各接口返回值
安卓：getDeviceInfo.uuid 就是 App 持久化的 deviceId（已用外部导出文件核对，一加 PHB110 实测值一致）→ 可直接用。
iOS：同一个字段返回的是 IDFV，不是签到用的 deviceId → 必须另找，见下面说明。
安卓：核对 / 兜底（不依赖本页）
  1. 文件管理器 → 内部存储/Pictures/wismcp/did/cpdaily_external_did.jpg，用「文本」方式打开，内容就是 deviceId。
  2. 或用数据线连电脑跑 python scripts/get_deviceid_android.py（免 root）。
  3. 还可以开 Debug 页：「我的」→ 设置 → 关于 → 3 秒内连点「版本号」7 次 → 返回「我的」→ Debug数据 → 看 device_id.json : 那一行。
Debug 标记是内存态，点完别杀 App 进程。三种方式取到的应是同一个值。
iOS：这个值本页拿不到，要从沙盒/备份取
  1. 数据线连电脑，用 爱思助手 或 iMazing 打开「今日校园」的沙盒文件。
  2. 找 Library/Preferences/com.wisedu.cpdaily.plist 里的 app_unique_uuid， 或 Documents/device/device_id.json。
  3. 取不到就退回抓包：python scripts/extract_deviceid.py --ext "<Cpdaily-Extension 头>"。
iOS 的 IDFV 与这个值无关，别用 getDeviceInfo.uuid 顶替。
